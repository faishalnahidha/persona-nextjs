# VS Code Copilot Frontend Guidelines

## Quick Reference for Frontend Development

### Styling

- **Tailwind CSS only** — no custom CSS, inline styles, or style props
- Apply classes via `className` attribute
- Use design tokens from `globals.css`
- Responsive: sm, md, lg, xl, 2xl breakpoints

### Components

- **Shadcn/UI first** for interactive elements
- Check installed: `npx shadcn@latest list`
- Install: `npx shadcn@latest add [component-name]`
- Import: `@/components/ui/[component-name]`
- Use built-in variants; extend in component if needed

### Icons

- '@tabler/icons-react' primary
- 'lucide-react' fallback
- Import: `import { IconName } from '@tabler/icons-react'`

### React & Next.js

- **Server Components by default** (no 'use client' unless needed)
- Use route groups: `(public)`, `(protected)`, `(auth)`, `admin/`
- Forms: React Hook Form + Zod validation

### Database & API

- Always call `connectDB()` in routes
- Use `.lean()` for JSON serialization
- Static methods in models (e.g., `Assessment.calculateResult()`)
- API responses typed with TypeScript interfaces

### Error Handling

- Add `error.tsx` files in route groups
- API: Validate with Zod → respond `{ error: string }`
- Client: try/catch on fetch → user-friendly messages

### DO NOT

- Add comments explaining obvious code
- Add unrequested features
- Use libraries beyond: Next.js, React, Tailwind, Shadcn, Tabler Icons, Lucide React, React Hook Form, Zod
- Use raw hex or pixel measurements
- Create extra components unless asked
- Hallucinate Penpot design properties
